Política de privacidad

Responsable: Maykol Santos Lazo · Última actualización: 1 de octubre de 2026

Alcance: Flux es software de código abierto. Esta página describe la copia de escritorio que su responsable utiliza para sus propias cuentas y la web estática de Flux. No existe un servicio central de cuentas bancarias ni una base de datos de movimientos operada por el responsable para otras personas. Cada persona que descarga el código y configura una instalación propia usa su propia instancia, sus credenciales de Enable Banking y sus propias cuentas.

Qué datos trata la copia de escritorio

Si se configura la conexión bancaria, Flux guarda en el propio ordenador los movimientos importados (descripción, importe, moneda, fecha, estado e identificador técnico), los identificadores de cuenta y la sesión bancaria necesaria para consultar los datos. También guarda el Application ID, la ruta local a la clave privada RSA y la clave privada del certificado HTTPS de retorno local. Los gastos introducidos manualmente se guardan en el almacenamiento local del dispositivo.

Cómo funciona la conexión bancaria

Flux no solicita ni recibe las credenciales bancarias. La autorización se realiza en la página o aplicación del banco. Flux envía a Enable Banking solicitudes para listar bancos, iniciar la autorización, crear o revocar la sesión y leer los movimientos autorizados. La clave privada RSA permanece en el equipo y firma localmente las solicitudes. El certificado HTTPS de retorno se limita a localhost y puede importarse como certificado de confianza de servidor en el almacén del usuario en Linux, Windows o macOS.

La conexión de Enable Banking está diseñada para el uso personal del titular de la aplicación con cuentas propias vinculadas. No se ofrece acceso bancario compartido a otras personas. Enable Banking y el banco tratan los datos conforme a sus propios avisos y condiciones: privacidad de Enable Banking y las condiciones del banco elegido.

Almacenamiento y conservación

Los datos bancarios se guardan en la base local del ordenador; no se sincronizan con servidores de Flux. La PWA guarda gastos manuales en el almacenamiento local del navegador. GitHub Pages sirve los archivos estáticos y GitHub puede tratar datos técnicos de las solicitudes a su servicio según su política de privacidad.

En escritorio, Desconectar intenta revocar la sesión de Enable Banking y elimina de la base local la sesión y los movimientos importados; no elimina los gastos manuales ni la configuración o la clave privada. Para borrar toda la copia local, cierra Flux y elimina la carpeta de datos y configuración correspondiente:

  • Windows: %LOCALAPPDATA%\flux-gastos y %APPDATA%\flux-gastos.
  • macOS: ~/Library/Application Support/flux-gastos.
  • Linux: ~/.local/share/flux-gastos y ~/.config/flux-gastos.

La PWA se borra eliminando los datos del sitio Flux desde las opciones de almacenamiento del navegador. Las copias de seguridad del dispositivo pueden conservar archivos eliminados.

Uso exclusivamente personal

La conexión bancaria de esta aplicación se configura para el uso privado de su titular. La publicación del código fuente no comparte la aplicación Production, su Application ID ni su clave privada. Quien utilice una copia independiente debe configurar su propia aplicación y obtener las autorizaciones correspondientes. Esta página no describe un servicio alojado para terceros.
