Política de privacidad

Responsable: Maykol Santos Lazo · Actualizada: 1 de octubre de 2026

Alcance: Flux es software de código abierto. Esta página describe la copia de escritorio que su responsable utiliza para sus propias cuentas y la web estática de Flux. No existe un servicio central de cuentas bancarias ni una base de datos de movimientos operada por el responsable para otras personas. Cada persona que descarga el código y configura una instalación propia usa su instancia y sus propias cuentas.

Datos tratados en la copia de escritorio

Si se configura la conexión bancaria, Flux guarda en el ordenador los movimientos importados (descripción, importe, moneda, fecha, estado e identificador técnico), identificadores de cuenta y sesión bancaria. También guarda el Application ID y la ruta local a la clave privada RSA. Los gastos manuales se guardan en el almacenamiento local del dispositivo.

Conexión bancaria

Flux no solicita ni recibe credenciales bancarias. La autorización ocurre en la página o aplicación del banco. Flux envía a Enable Banking solicitudes para listar bancos, iniciar la autorización, crear o revocar la sesión y leer los movimientos autorizados. La clave privada RSA permanece en el equipo y firma localmente las solicitudes. Esta conexión se destina al uso personal del titular con sus propias cuentas vinculadas.

Enable Banking y el banco elegido tratan datos según sus propios avisos: privacidad de Enable Banking y condiciones del banco.

Almacenamiento, conservación y borrado

Los datos bancarios se guardan en la base local del ordenador; Flux no sincroniza movimientos con un servidor central. La PWA guarda gastos manuales en el almacenamiento local del navegador. GitHub Pages sirve los archivos y GitHub puede tratar datos técnicos de las solicitudes según su política de privacidad.

Desconectar intenta revocar la sesión de Enable Banking y elimina de la base local la sesión y movimientos importados; no borra gastos manuales ni la configuración o clave privada. Para borrar todo, cierra Flux y elimina:

  • Windows: %LOCALAPPDATA%\flux-gastos y %APPDATA%\flux-gastos.
  • macOS: ~/Library/Application Support/flux-gastos.
  • Linux: ~/.local/share/flux-gastos y ~/.config/flux-gastos.

La PWA se borra eliminando los datos del sitio Flux desde el navegador. Las copias de seguridad pueden conservar archivos eliminados.
