Condiciones de uso

Responsable: Maykol Santos Lazo · Última actualización: 1 de octubre de 2026

Flux es software de código abierto para uso personal. No es un servicio bancario alojado ni ofrece a terceros acceso a la aplicación Production de Enable Banking de su responsable.

Qué ofrece Flux

Flux permite registrar gastos manualmente y visualizar pagos que parecen repetirse. La conexión bancaria opcional está disponible en las versiones de escritorio compatibles. Flux no inicia pagos, no mantiene cuentas bancarias y no ofrece asesoramiento financiero, fiscal ni de inversión. Las categorías, importes y estimaciones pueden ser inexactos; compruébalos con los datos del banco.

Conexión bancaria personal

La conexión bancaria de Enable Banking debe utilizarse solo para uso personal del titular y sus cuentas propias vinculadas, de acuerdo con las condiciones de Enable Banking y las condiciones del banco. No compartas el Application ID ni la clave privada de tu aplicación con otras personas y no uses esta aplicación personal para dar acceso a cuentas de terceros. Enable Banking requiere un acuerdo para ofrecer su API al público.

Las credenciales bancarias se introducen únicamente en las páginas o aplicaciones oficiales del banco. Flux guarda localmente la clave privada para firmar solicitudes y usa un certificado de servidor local para recibir el retorno HTTPS de la autorización en localhost. Puedes desconectar la cuenta desde Flux; para instrucciones de almacenamiento y borrado consulta la política de privacidad.

Datos y dispositivos

Los datos se guardan localmente en cada dispositivo y no se sincronizan entre dispositivos mediante Flux. Cada persona que descargue y ejecute una copia independiente debe configurar sus propios servicios y autorizaciones. El autor no recibe los movimientos bancarios de las instalaciones independientes de otras personas.

Disponibilidad y terceros

La disponibilidad de bancos depende de Enable Banking y de cada banco y puede cambiar. El software se proporciona tal cual y sin garantía de funcionamiento ininterrumpido, en la medida permitida por la ley. Enable Banking o el banco pueden aplicar sus propias condiciones o tarifas; compruébalas directamente con ellos.
